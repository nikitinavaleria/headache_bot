# headache_bot

Телеграм-дневник головной боли на aiogram 3.

## Запуск

1. Скопировать `.env.example` в `.env`, вписать токен бота (@BotFather) и свой Telegram user_id (@userinfobot).
2. `python main.py` (интерпретатор — `.venv`, Python 3.13).

Пока бот запущен (время московское): пинги каждые 2 часа с 9:00 до 23:00, напоминание про таблетки в 11:30 и 15:30, CSV в 23:00.

## Команды

- `/pain` — записать эпизод (опросник из дневника)
- `/end` — проставить время окончания эпизода, если при опросе нажала «Ещё болит»
- `/stats [week|month|all]` — статистика
- `/export` — выгрузить `episodes.csv` и `pings.csv` (также приходят автоматически в 23:00)
- `/cancel` — прервать опрос
