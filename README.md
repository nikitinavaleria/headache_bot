# headache_bot

Телеграм-дневник головной боли на aiogram 3.

## Что умеет

- `/pain` — пройти опросник и записать эпизод головной боли. Если препарат принимался,
  бот спросит время приёма и через сколько отпустило
- `/end` — проставить время окончания эпизода: «прямо сейчас» или ввести время
- `/episodes` — посмотреть последние записи, поправить любое поле, удалить запись или добавить пропущенный эпизод задним числом
- `/stats [week|month|all]` — статистика
- `/export` — выгрузить `episodes.csv`, `pings.csv`, `pills.csv`
- `/cancel` — прервать опрос

По расписанию (московское время):

- каждые 2 часа с 9:00 до 23:00 — «У тебя болит голова?», а если эпизод открыт — «Голова всё ещё болит?».
  Ответ на любой из вопросов убирает из чата предыдущие, оставшиеся без ответа
- каждый час с 9:00 до 23:00 — «Боль прошла?», если после приёма препарата прошёл час, а боль ещё идёт
  (обычный вопрос про голову в это время не задаётся, чтобы не дублировать)
- 11:30 и 15:30 — напоминание про таблетки с отметкой «выпила / не выпила»; если ответа нет, через час повторяется, а ответ убирает первое напоминание
- 23:00 — CSV с данными

Когда эпизод закрывается, бот сам считает, через сколько после таблетки отпустило.

Если эпизод остался незакрытым до следующего дня, бот закрывает его временем 23:00 («болела до вечера»)
и сообщает об этом — поправить можно в `/episodes`.

## Запуск в Docker (сервер)

```bash
cp .env.example .env   # вписать BOT_TOKEN и USER_ID
docker compose up -d --build
docker compose logs -f
```

База лежит в `./data/headache.db` на хосте, переживает перезапуски и обновления образа.
Обновить после `git pull`: `docker compose up -d --build`.

## Запуск локально

1. Скопировать `.env.example` в `.env`, вписать токен бота (@BotFather) и свой Telegram user_id (@userinfobot).
2. `python main.py` (интерпретатор — `.venv`, Python 3.13).

### Автозапуск на macOS (launchd)

Готовый агент лежит в `launchd/com.headache_bot.plist`. Пока он не скопирован в `~/Library/LaunchAgents`,
бот на маке не запускается — так и надо, если он работает на сервере.

```bash
cp launchd/com.headache_bot.plist ~/Library/LaunchAgents/          # включить автозапуск
launchctl load ~/Library/LaunchAgents/com.headache_bot.plist
launchctl bootout gui/$(id -u)/com.headache_bot                    # выключить
rm ~/Library/LaunchAgents/com.headache_bot.plist                   # и убрать из автозапуска
tail -f logs/bot.log                                               # смотреть лог
```

`launchctl unload` действует только до следующего входа в систему — чтобы бот не вернулся,
файл нужно убрать из `~/Library/LaunchAgents`.

## Важно: только один запущенный экземпляр

Telegram отдаёт обновления одному боту на токен. Две копии (например, на ноутбуке и на сервере)
не мешают друг другу отвечать, но каждая шлёт свои сообщения по расписанию — получаются дубли,
а в логе появляется `TelegramConflictError: terminated by other getUpdates request`.
Держать запущенной нужно ровно одну.
